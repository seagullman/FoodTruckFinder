# Product Overview

FoodTruckFinder is an iOS mobile application that helps users discover and locate food trucks in their area. The app provides location-based search functionality, detailed food truck information including menus, and navigation services to help users find their favorite mobile food vendors.

## Key Features
- Location-based food truck discovery with distance filtering (1-20 miles)
- Interactive map view showing food truck locations
- Detailed food truck profiles with menus, descriptions, and operating hours
- User authentication and account management
- Navigation integration for directions to food trucks
- Real-time location tracking and distance calculations

## Target Platform
- iOS mobile application built with SwiftUI
- Requires location permissions for core functionality
- Integrates with device maps for navigation
